🥇 Level 1: Personal Portfolio Website

A clean, responsive personal portfolio designed to showcase my background, technical skill set, and independent projects.
🚀 Features Included

    Header Section: Clean navigation bar featuring a personalized logo/name and a memorable professional tagline.

    About Me: A dedicated section introducing my background, core motivations, and a professional profile image.

    Skills Matrix: A categorized, visually structured list of technical competencies and toolkits.

    Projects Showcase: Cards displaying past work, including project titles, descriptions, and preview images.

    Resume Download: A direct, accessible link to download my professional resume in PDF format.

    Contact & Footer: A functional contact details zone mapped with social links and a standard copyright notice.

🛠️ Core Concepts Practiced

    Semantic HTML5 tags (<header>, <section>, <article>, <footer>).

    CSS Box Model (padding, margins, borders, and content alignment).

    Document flow and positioning static elements cleanly.

🥈 Level 2: Creative Product Landing Page

A visually striking, marketing-focused landing page built to master advanced CSS layouts, component alignment, and design consistency.
🚀 Features Included

    Hero Section: High-impact heading, sub-headline, and an prominent Call-to-Action (CTA) button.

    Features/Benefits Grid: Multi-column layout separating product value propositions.

    Visual Assets: Carefully curated imagery integrated with smooth CSS transitions.

    No-Overlap Architecture: Structured structural boundaries ensuring text and layout components remain distinct on various window sizes.

🛠️ Core Concepts Practiced

    CSS Flexbox & Grid: Managing complex multi-column layouts and centering elements effortlessly.

    UI/UX Design Fundamentals: Working with a cohesive color palette, typographic hierarchy, and white space.

    Responsive Design Principles: Utilizing relative units (rem, em, %) and media queries to prevent overlapping text.

🥉 Level 3: Interactive JavaScript Calculator

A fully functional, interactive digital calculator built to bridge the gap between static styling and dynamic logic computation.
🚀 Features Included

    Dynamic Display Screen: Real-time feedback showing current user input sequences alongside calculated results.

    Grid Layout Engine: Clean, symmetrical alignment of numbers and operator keys using CSS Grid.

    Full Math Suite: Support for addition, subtraction, multiplication, and division, along with clear (C) actions.

🛠️ Core Concepts Practiced

    JavaScript Event Listeners: Capturing DOM click events across multiple physical buttons.

    Control Flow & Logic: Implementing conditional statements (if/else or switch) to parse mathematical operations safely.

    State Management: Handling operator precedence, input string concatenation, and updating the UI dynamically.
